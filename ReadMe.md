# Hi, I'm Gabriel Le Breton, aka GabLeRoux 👋

I build games, tools, and automation, sometimes for fun, sometimes to make computers do the boring stuff so humans can do the fun stuff.

I work across game development, CI/CD, testing, open source tooling, and developer experience. At [TLM](https://tlmgo.com/), I help non-technical entrepreneurs turn “I have an idea, but the tech part is a fog machine” into actual software products.

I speak `French`, `English`, and several programming languages.

🌐 Read more at [gableroux.com](https://www.gableroux.com/)
